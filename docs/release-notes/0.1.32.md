# Dekubi X 0.1.32 (2026-11-26)

## Highlights

- **FSR 1.0 Presentation Upscaling (`DEKUBI_UPSCALE=fsr1`)**:
  - Added D3D12 HLSL `cs_5_1` compute passes for AMD FidelityFX FSR 1.0 Edge-Adaptive Spatial Upsampling (EASU) and Robust Contrast-Adaptive Sharpening (RCAS) in `crates/ally-gpu/src/present_fx.rs`.
  - Automatically upscales sub-1080p render-scaled frames (`DEKUBI_OUTPUT=1080p` + `DEKUBI_RENDER_SCALE=67..75`) cleanly to 1920x1080 (override with `DEKUBI_UPSCALE_SIZE=1080p|1440p|4k|WxH` and `DEKUBI_FSR_SHARPNESS=<0.0..=2.0>`, default `0.2`).
  - Zero overhead when off (direct `CopyResource` fast path untouched).
- **FSR 3 Optical-Flow Frame Generation (`DEKUBI_FRAME_GEN=fsr3`)**:
  - Ported the half-resolution shared-memory diamond optical-flow shader and 3x3 median bidirectional interpolation shader from `Dekubi-Ally-github` (`fsr3_optical_flow.comp` + `fsr3_frame_interpolation.comp`) into D3D12 `PresentFx`.
  - Presents an interpolated midpoint frame (`t = 0.5`) ahead of each real frame (`t = 1.0`), with color-difference occlusion damping and anti-flicker center blending.
- **Series S Environment Mode (`DEKUBI_CONSOLE=series-s`) & Fast Preset**:
  - `launch_default()` now honors `DEKUBI_CONSOLE=series-s` so launcher `.cmd` files can start Series S mode with full logging and warm-up UI.
  - Added `Play Dekubi X (Series S Fast + FG).cmd` alongside `Play Dekubi X.cmd` and `Play Dekubi X (safe).cmd`.
