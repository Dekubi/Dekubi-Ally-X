# Dekubi X 0.1.33 (2026-11-27)

## Highlights

- **Asynchronous Batched Logging** (ported from `neptune-dolberth-nvidia-8gb` `658d561`, GPL-3.0-or-later):
  - `INFO` and below log writes to both `stderr` and per-launch log files are now batched up to 256 KiB on dedicated background threads (`DEKUBI_LOG_SYNC=1` restores synchronous writes).
  - `WARN` and `ERROR` lines still write synchronously so crash logs are always flushed to disk.
- **Lock-Free Write-Watch `known_view`** (ported from `neptune-dolberth-nvidia-8gb` `658d561`):
  - Added lock-free `KNOWN_VIEW` bitmap mirroring `Guards::protected | absent | viewed` so `known_view()` answers without taking the `GUARDS` lock under the journal's write lock.
- **AVX2 All-Zero Descriptor Page Skip** (ported from `neptune-dolberth-nvidia-8gb` `658d561`):
  - `HostHeap::mirror_copied_page` checks changed 4 KiB descriptor pages with `_mm256_testz_si256` on AVX2 CPUs and skips hashing all 128 slots when the page is zero and unseen.
- **8 GB VRAM & Pipeline Stability** (ported from `victory-fork` `af23c65`, `a463dcb`, `46da5ee`):
  - `#1320`: `submit_split` calls `list::tables_done` after `host.execute(&now)` so dynamic descriptor slots are returned immediately.
  - `#1336`: `resource::alias_of` returns `Option<Held>` pinned under `TARGETS_AT`'s lock, preventing use-after-free when a title releases a target during an alias copy.
  - `#1353`: `Pending::make` catches panics during host pipeline compilation and notifies waiters instead of stalling for the frame budget.
