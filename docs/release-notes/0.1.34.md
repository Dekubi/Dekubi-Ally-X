# Dekubi X 0.1.34 (2026-11-27)

## Highlights

- **Native Host DXR 1.1 Stages 1 + 2** (ported from `Linox-IDK/LNX-victory` `c04e615`, GPL-3.0-or-later, off by default):
  - **`DEKUBI_BVH_HOOK=1`** (`crates/ally-hle/src/bvh_hook.rs`, `crates/ally-loader/src/windows.rs` `wrap_imports`): intercepts all 7 `XboxBvhBuilder.dll` imports (`ctor`, `dtor`, `BuildRaytracingAccelerationStructureBatched2X`, `RehydrateRaytracingAccelerationStructureBatched2X`, `GetRaytracingAccelerationStructurePrebuildInfo`, `CopyRaytracingAccelerationStructure`, `Set64BitMortonCodes`) and logs counts/geometries every 5 seconds.
  - **`DEKUBI_NATIVE_BVH=1`** (`crates/ally-gpu/src/native_rt.rs`): mirrors BLAS and TLAS builds onto native host D3D12 DXR 1.1 (`ID3D12Device5` + `ID3D12GraphicsCommandList4`) with static-BLAS signature reuse and 300-frame idle eviction.
- **2D Texture Mip Reduction (`DEKUBI_MIP_SKIP=0..=3`)** (`crates/ally-gpu/src/texture.rs`):
  - Skips top mip levels on large plain 2D on-demand textures (`>= 512px`, `>= 4` mips), saving ~4.5 GB VRAM on 8 GB GPUs while automatically shifting `MostDetailedMip` via `tiles::show_from`.
- **Asynchronous FSR 1.0 Present** (`crates/ally-gpu/src/present_fx.rs`, `host.rs`):
  - Added an 8-frame shader-visible descriptor ring so FSR 1.0 upscaling executes asynchronously on `p.ahead` via `execute_own`, eliminating the synchronous present GPU wait.
