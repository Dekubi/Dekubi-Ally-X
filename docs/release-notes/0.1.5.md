# Dekubi X 0.1.5 (2026-11-25)

## Added
- `apps/dekubi-ally/src/scskiller.rs`: the pre-launch part of Dekubi Ally's
  SCSKiller (Fritchii `src/yuzu/dekubi/scskiller.cpp`, `RunScsKillerOnGameLaunch`),
  ported to Rust: NVAPI DRS shader cache size to 10 GB (setting 0x00AC8497),
  `D3D Shader Cache` Disk Cleanup Autorun=0, driver stamp
  `<cache>/scskiller_driver.txt`. Runs before the shader warm-up.

## Not ported
- The SCSKiller window and its per-game cache view (Qt).
- The driver-change cache wipe: Dekubi X's DXIL cache does not depend on the
  driver, and D3D12 refuses a pipeline library made by another driver itself.
- AMD and Vulkan settings: not used here (NVIDIA, D3D12).
