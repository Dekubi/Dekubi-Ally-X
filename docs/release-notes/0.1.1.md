# Dekubi X 0.1.1 (2026-11-25)

Private build. Not for distribution (contains GPL-2.0-only XCL-derived code).

## Changes

- Ported victory-fork 9376fd6 (fxceless) on VIctory ffe310e (Marvisak and
  contributors) into `crates/ally-*` and `apps/dekubi-ally`; crates, env vars
  (`DEKUBI_*`), root marker (`.dekubi-root`), user-facing names renamed.
- `ally-core::notes` + `NOTES.toml`, `dekubi-x notes`, notes printed around `run`.
- `scripts/build.ps1` (makes `Dekubi X.exe`), `scripts/play.ps1` (after ztrx).
- Lint fixes for `clippy -D warnings`: `ally-gpu` draw.rs (sort), indirect.rs
  and resource.rs (dead code allowed, kept for later).

## Verified

- `cargo clippy --workspace --all-targets --target x86_64-pc-windows-msvc -D warnings`: clean (cross-check, Linux host).
- `cargo fmt --all --check`: clean.
- Not yet: `cargo test` and a launch on Windows.

## Known gaps

- Missing 319 newer VIctory fixes (TDR handling, bindless views, depth twins);
  merging them conflicts in 48 files. Port one by one.
- `console_insn*.rs` is XCL-derived (GPL-2.0-only).
