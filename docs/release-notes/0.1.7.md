# Dekubi X 0.1.7 (2026-11-25)

Four features after Dekubi Ally (Fritchii, `src/yuzu/dekubi/`), rewritten for a
D3D12 front end without Qt:

| Dekubi Ally | Dekubi X |
|---|---|
| `perf_overlay.cpp` | `apps/dekubi-ally/src/monitor.rs` (`overlay`): Win32 layered click-through window, GDI text, 2 updates a second, F10 |
| `dekubi_summary` (log sharing) | `monitor.rs`: `logs/last-summary.txt`, local only, nothing sent |
| `hardware_recommend.cpp` | `apps/dekubi-ally/src/hardware.rs`: DXGI card memory to display mode and texture levels |
| `game_controls.cpp` | `crates/ally-hle/src/modules/controls.rs`: `controls.txt` key and pad remap |

Frame numbers come from `crates/ally-gpu/src/stats.rs`, filled by the frame meter once a second.
