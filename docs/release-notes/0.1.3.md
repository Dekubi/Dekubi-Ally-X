# Dekubi X 0.1.3 (2026-11-25)

## Fixed
- `ally-gpu` `HostHeap::dynamic`: the slot walk was capped at `DYNAMIC`
  entries. The search chain is `cursor..end` then `0..cursor+n-1` (VIctory
  #974), so with the cursor inside the ring the cap stopped the walk before
  the run across the cursor was seen. A table that fit was refused. The cap is
  removed; `enough` still skips the walk when too few slots are free.

## First launch (dekubi-auto.ps1, 2026-11-25 18:20)

- Boot: 0 missing imports, 30 fps, about 21 draws a frame for 5 minutes.
- 30 warnings from device methods 0x1c8 and 0x218 (pipeline creation, layout
  unknown in every reference fork). The title skips those pipelines.
- The title stays on its first-boot screens: the launcher sends no input.
